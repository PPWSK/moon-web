MOON — USB Recovery

Reflash a MOON controller over its USB-C port, when Bluetooth cannot reach it

This browser cannot talk to USB devices

USB recovery needs the Web Serial API.

Use Google Chrome or Microsoft Edge on a computer (Windows, macOS, Linux or ChromeOS). Phones and tablets cannot do this — Web Serial is desktop only.

When to use this

Use this when the lamp cannot be reached over Bluetooth at all — it does not appear, or it connects and drops again after a few seconds. This route does not use the MOON's own software, so it still works when that software is crashing. It writes a complete, fresh firmware.

If Bluetooth still works, use the wireless update instead — it needs no cable.
What you need: the controller's USB-C port, a USB-C cable to your computer, and the lamp powered on as usual. Nothing needs to be opened beyond reaching the controller box, and there are no buttons to hold — the board resets itself.

Install

  1. Plug a USB-C cable from the controller into this computer
  2. Press Choose USB port and pick the entry that appears (often "FT231X" or "USB Serial")
  3. Press Install firmware and leave it alone for about a minute
